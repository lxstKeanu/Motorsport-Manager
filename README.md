# Garage Racing (рабочее название)

Тайкун про гоночную команду, которая начинается со старого сломанного седана в гараже. Дизайн игры — в [docs/GDD.md](docs/GDD.md).

## Запуск

1. Установить [Godot 4.7](https://godotengine.org/download) (обычную версию, не .NET).
2. В Godot: **Import** → выбрать `project.godot` в этой папке.
3. Нажать **F5**. Откроется главное меню.

## Что уже есть

- Главное меню: «Продолжить» (неактивна, пока нет сохранений), «Новая игра» (пока заглушка), «Настройки», «Выход».
- Настройки: язык, полный экран, общая громкость, музыка, звуки. Сохраняются в `user://settings.cfg`.
- Два языка — английский и русский. Переключаются в настройках или кнопками EN / RU в правом нижнем углу меню.

## Тексты и переводы

Все тексты лежат в `localization/translations.csv` (колонки `keys,en,ru`). В сценах и коде пишется только ключ:
- в сцене — `text = "MENU_NEW_GAME"`, Godot переведёт сам;
- в коде — `tr("MENU_VERSION")`.

Чтобы добавить текст, добавь строку в CSV (удобно править в Excel или LibreOffice) и используй ключ. После правки CSV Godot сам переимпортирует переводы при открытии редактора.

## Проверки

```bash
godot --headless --path . --import
godot --headless --path . res://tests/test_runner.tscn
```

Проверяется:
- у каждого ключа есть английский и русский текст;
- все ключи из сцен и скриптов есть в таблице;
- переводы импортированы;
- настройки сохраняются и применяются к звуковым шинам;
- главное меню и окно настроек работают.

Код выхода `0` — всё прошло.

## Структура

| Путь | Что там |
|---|---|
| `scenes/main_menu/` | Главное меню и фон-чертёж |
| `scenes/ui/` | Общие окна (настройки) |
| `scenes/new_game/` | Экран новой игры (пока заглушка) |
| `scripts/autoload/` | Глобальные синглтоны (`Settings`) |
| `ui/theme.tres` | Тема интерфейса: цвета, шрифты, стили кнопок |
| `localization/` | Таблица переводов |
| `assets/fonts/` | Шрифты Oswald и Inter (лицензия SIL OFL 1.1, файлы `OFL-*.txt`) |
| `tests/` | Автопроверки |
